# Sons de l'application

Ce dossier contient les fichiers audio utilisés dans l'application.

## Fichiers requis :

- `beep.mp3` - Son de bip classique pour le scan
- `success.mp3` - Son de succès
- `notification.mp3` - Son de notification
- `cash_register.mp3` - Son de caisse enregistreuse

## Notes :

- Les fichiers doivent être au format MP3
- Durée recommandée : 0.5 à 2 secondes
- Volume modéré pour ne pas être intrusif

## Remplacement :

Pour remplacer les sons, ajoutez simplement les fichiers MP3 avec les noms exacts ci-dessus dans ce dossier.
